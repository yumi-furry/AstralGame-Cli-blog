中继服务器与游戏目录

服务器通过中继（relay）节点与其他客户端互通，房间创建时只把已启用的服务器写入邀请载荷。

服务器列表（servers.json）

字段类型说明
idint本地自增主键
namestring用户可读名称
uristringEasyTier 监听 URI（如 tcp://1.2.3.4:11010）
enabledbool是否启用：只有启用的服务器才会被写入新建房间的 peers
sort_orderint排序序号
  • 首次运行（文件不存在）返回内置默认列表：公共中继（tcp://public.easytier.cn:11010，已启用）；
  • 文件损坏时返回空列表，避免坏数据导致面板不可用。

面板 / API 操作

操作接口说明
列表GET /api/servers全部中继服务器
新增POST /api/servers请求体 name、uri；默认启用
修改PUT /api/servers/:idname/uri/enabled 可选，局部更新
删除DELETE /api/servers/:id条目不存在返回 404
测速GET /api/servers/ping并发 TCP 连接测延迟

测速说明

  • 每个服务器一个并发任务，避免串行等待超时；
  • 从 URI 解析 host:port，测量 TCP 握手耗时；缺省端口按 EasyTier 默认 11010；
  • 成功返回毫秒数；连接失败或 5 秒超时返回 -1（前端显示「超时」）。

内置游戏目录

GET /api/games 返回内置游戏目录（硬编码），id 用于建房请求：minecraft、grand_theft_auto_v、mindustry、raft、forged_alliance、valheim、ark、dont_starve_together、factorio、left_4_dead_2、palworld、project_zomboid、rust、satisfactory、seven_days_to_die、stardew_valley、terraria、v_rising，以及 custom（自定义网络）。

REST API 参考

所有业务接口挂在 /api 下，除登录 / 登出与第三方 WebSocket 服务端点外，统一经过鉴权中间件。

鉴权方式

方式适用场景说明
Cookie 会话浏览器面板登录下发的 astral_session Cookie（HttpOnly + SameSite=Lax）；重启后失效
HTTP Basic Authcurl / 外部脚本Authorization: Basic base64(username:password)，用户名不允许含 :

未配置用户名（username 为空）时关闭鉴权。未通过鉴权返回 401 {"error":"unauthorized"}。

路由总览

接口方法说明
/api/statusGET节点状态快照（前端 3 秒轮询）
/api/logs?tail=NGET节点日志，默认 200 条、上限 800 条
/api/profileGET/PUT资料 / 网络 / 守护进程设置（头像 base64 内联）
/api/configGET/PUT读取 / 保存 config.toml
/api/startPOST启动（重启）EasyTier 实例，可携带完整 TOML
/api/stopPOST停止当前实例
/api/restartPOST用最近一次配置重启实例
/api/credentialsGET/POST/DELETE进网凭据生成 / 列表 / 撤销（ttl_seconds、reusable）
/api/room/createPOST创建房间
/api/room/joinPOST加入房间
/api/room/leavePOST离开房间
/api/room/currentGET当前房间与分享链接
/api/serversGET/POST服务器列表 / 新增
/api/servers/pingGET并发测速，返回 TCP 连接耗时
/api/servers/:idPUT/DELETE修改 / 删除服务器
/api/gamesGET内置游戏目录
/api/wsGET面板端 WebSocket 升级
/api/ws/serviceGET第三方服务 WebSocket（ws_key 鉴权）
/api/ws/keyGET查看第三方服务密钥
/api/ws/key/rotatePOST刷新密钥（旧密钥失效，已连接服务断开）
/api/ws/servicesGET在线第三方服务列表
/api/smtpGETSMTP 配置摘要（密码不回传）
/api/smtp/recipientsPUT更新收件人列表
/api/smtp/testPOST发送测试邮件
/api/smtp/send-nowPOST一键发送当前房间详情
/api/update/checkGET检查 GitHub 最新发行版
/api/update/applyPOST应用更新（download_url，仅 GitHub 白名单域名）
/api/auth/loginPOST登录（免鉴权）
/api/auth/logoutPOST登出（免鉴权）

调用示例

bash
# 登录并取得 Cookie
curl -c cookies.txt -X POST http://<服务器>:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"yourpass"}'

# Cookie 获取状态
curl -b cookies.txt http://<服务器>:8080/api/status

# 或直接 Basic Auth
curl -u admin:password http://<服务器>:8080/api/room/current
curl -u admin:password -X POST http://<服务器>:8080/api/room/leave
curl -u admin:password -X POST http://<服务器>:8080/api/smtp/test

错误响应统一为 {"error":"..."} 并携带对应 HTTP 状态码。

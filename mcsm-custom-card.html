通过自定义 HTML 卡片接入 MCSM 管理面板

把 AstralGame 服务器状态与当前房间成员列表（名字、延迟）以一张实时 WebSocket 卡片嵌入 MCSM 面板。

接入原理

MCSManager 支持添加「自定义 HTML」类型的应用卡片。卡片通过 /api/ws/service 连接 CLI，实时推送服务器状态与房间事件，并支持卡片内可视化配置连接。

  1. 卡片顶部配置区：填 WS 地址、密钥、服务名称、服务类型后点「连接」；
  2. 通过 ws://<地址>/api/ws/service?key=...&name=...&type=... 建立 WebSocket（系统随机密钥鉴权）；
  3. 连接成功收到 hello 后，发送只读指令 get_room_info 获取服务器状态与成员列表；
  4. 持续接收 snapshot / room.created / room.joined / room.left / server.started 事件实时更新，并定时重发 get_room_info；
  5. 点击「退出」按钮断开连接，配置可重新编辑。
重要：WS 地址必须填公网可达的地址。 MCSM 的 HTML 卡片本质上是一个独立的小浏览器，在访问面板的那台机器上发起 WebSocket 请求，而非 astral-server 所在服务器。不能填 127.0.0.1 或 localhost；须填写从访问面板的机器能连通的地止（公网 IP / 域名 + 端口），必要时为 /api/ws/service 配置公网映射 / 反向代理。

前置条件

  • astral-server 已运行，Web 管理端可访问（默认 http://<服务器IP>:8080）；
  • 需要知道第三方服务连接密钥 ws_key（面板「设置 → 第三方服务」查看与复制）；
  • get_room_info 为只读指令，不受 service_control_enabled 开关限制。

WebSocket 事件与指令

事件 / 指令说明
hello连接认证成功后首帧（含连接 ID、名称、类型）
snapshot / server.started连接后快照 / 服务启动
room.created / room.joined / room.left房间创建 / 加入 / 离开
get_room_info只读指令，应答 result，data 含 running、uptime_secs、room、share_url、node、members

成员 cost：0 = 本机，1 = 直连，>1 = 经中继。卡片默认过滤 cost > 1 的中继节点。

WebSocket 事件推送

第三方软件可通过 WebSocket 实时获取房间内容、房间码与运行状态，无需轮询。1.4.2_4 起支持发送控制指令。

两个端点与鉴权差异

端点面向对象鉴权方式
/api/ws浏览器面板与 REST 一致：Cookie 会话或 Basic Auth（ws://admin:password@host:port/api/ws）
/api/ws/service?key=&name=&type=AstrBOT 等第三方服务系统随机密钥 ws_key，不走面板账号

第三方服务端点：密钥启动时自动生成（也可手动指定 ws_key）；刷新密钥后旧密钥立即失效，已连接服务被断开。

事件类型

事件触发时机room 字段
snapshot连接建立后立即推送当前房间或 null
server.started服务启动完成（重启后自动恢复房间）当前房间或 null
room.created服务器创建新房间新房间
room.joined服务器加入目标房间目标房间
room.left服务器离开房间null
audit产生操作记录（登录 / 登出 / 修改操作）时推送（1.5.1_1 起）无（见下方 entry 字段）

audit 事件（1.5.1_1 起）

面板端与第三方服务端点都会收到。

json
{
  "event": "audit",
  "timestamp": 1792059565,
  "entry": {"ts": 1792059565, "kind": "login", "action": "登录成功", "ip": "192.168.1.10"}
}
  • entry.kind：login / login_failed / logout / modify / modify_denied（未授权的非 GET 请求尝试）。
  • entry.ip：操作者 IP（反向代理 X-Forwarded-For / X-Real-IP 头优先，否则取 TCP 源地址）。
  • 第三方 WS 控制指令的 action 带「第三方服务指令：」前缀。

调用示例

javascript
const proto = location.protocol === 'https:' ? 'wss' : 'ws';
const ws = new WebSocket(`${proto}://${location.host}/api/ws`);

ws.onmessage = (e) => {
  const msg = JSON.parse(e.data);
  if (msg.room) {
    console.log('房间码：', msg.room.short_code);
    console.log('邀请链接：', msg.share_url);
  }
};

第三方服务指令协议（1.4.2_4 起）

连接成功后除被动接收事件外，可发送指令并收到应答。控制类指令需开启 service_control_enabled；只读 get_room_info 不受限制。

action说明额外字段
get_room_info查询房间类型、成员列表（含延迟）、运行时长无
restart用最近一次配置重启实例无
close关闭房间（停止实例并清空当前房间）无
open开启房间（带 game_id/game_name 建房；不带则重放上次配置）game_id、game_name、display_name
join加入房间input（短码 / 链接 / AG1. 离线串）
json
{"id":"r1","action":"get_room_info"}
{"id":"r4","action":"open","game_id":"minecraft","game_name":"我的世界"}
{"id":"r6","action":"join","input":"ABC123"}

应答统一为 {"event":"result","id":...,"ok":bool,"error":...,"data":...}。get_room_info 的 data 含 running、uptime_secs、room、share_url、node、members（成员含 latency_ms 实测延迟与 loss_rate）。

SMTP 邮件通知

当服务器重启、或房间码发生变动时，系统会自动发送同风格 HTML 邮件给收件人列表。

第 1 步：配置 SMTP 服务器

toml
[astral_server.smtp]
enabled = true
host = "smtp.qq.com"          # 见下表
port = 465
username = "your_mail@qq.com"
password = "授权码"            # 注意是 SMTP 授权码，不是邮箱登录密码
from_name = "Astral Server"
from_email = "your_mail@qq.com"
encryption = "tls"            # 465 端口用 tls；587 用 starttls；内网不加密用 none
recipients = ["friend@example.com"]
字段说明
hostSMTP 服务器主机
portSMTP 端口（TLS 一般 465，STARTTLS 一般 587）
username / password登录用户名 / SMTP 授权码
from_name / from_email发件人显示名 / 邮箱
encryptiontls / starttls / none
recipients收件人邮箱列表（面板可维护并写回）

第 2 步：维护收件人并测试

重启服务后，打开面板「设置 → 邮件通知」：

  • 查看服务器配置摘要（主机、端口、加密方式、授权码是否已设置）；
  • 「收件人邮箱」每行一个邮箱，点「保存收件人」（自动去重并校验格式）；
  • 点「发送测试邮件」，收到即配置成功；
  • 点「一键发信」，立即将当前房间详情发给所有收件人；无房间时提示先创建或加入。

常见邮箱参数

邮箱host端口 / 加密授权码获取方式
QQ 邮箱smtp.qq.com465 / tls（或 587 / starttls）设置 → 账号 → POP3/SMTP 服务 → 开启 → 生成授权码
163 邮箱smtp.163.com465 / tls设置 → POP3/SMTP/IMAP → 开启 SMTP → 客户端授权码
Gmailsmtp.gmail.com465 / tls（或 587 / starttls）两步验证后生成「应用专用密码」；国内通常无法直连
Outlooksmtp.office365.com587 / starttls账号密码（部分账号需 OAuth）
注意事项：password 填授权码 / 应用专用密码；授权码存于 config.toml，请 chmod 600，面板接口不回传密码；邮件只在存在房间时发送；发送失败只记警告日志。

邮件模板自定义

首次运行后自动生成 Email/ 文件夹：room_notification.html（HTML 模板）与 room_notification.txt（纯文本模板）。直接编辑即可，无需重启（每次发信实时读取）。

模板变量

变量释义
{{EVENT_TITLE}}事件标题
{{EVENT_DESC}}事件描述
{{GAME_NAME}} / {{GAME_ID}}游戏名称 / 标识
{{SHORT_CODE}}房间码（短码或离线邀请串）
{{CODE_HINT}}房间码提示文字
{{SHARE_URL}}邀请链接
{{RUNNING}}运行状态
{{TOTAL_NODES}}在线节点数
{{SERVER_VERSION}}服务器版本

变量值已做 HTML 转义，可直接在 HTML 模板中使用。房间码优先取短码；服务不可用时回退为 AG1. 离线串。

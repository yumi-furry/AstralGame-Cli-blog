基于 Astral Game 二次开发的服务器版联机工具，组网内核为 EasyTier， 适配 Debian / Ubuntu 无头服务器，内置 Web 管理界面，可通过浏览器管理服务器、创建 / 加入房间。 当前版本 v1.5.1_1

核心特性

🕹️

联机房间

创建 / 加入房间，支持短码、AG1. 离线串与完整邀请链接。

👥

成员管理

自动过滤中继节点，仅显示真实用户；本机标记「本机」。

🛡️

网络设置

可开关「禁用 P2P 打洞」、TUN 虚拟网卡与静态虚拟 IP。

♻️

守护进程

开机自动加入 / 自动创建预设房间（二选一），重启免人工。

📡

WebSocket 推送

房间内容与状态实时广播，第三方服务可发送控制指令。

✉️

邮件通知

SMTP 配置后自动发送同风格 HTML 邮件，模板可自由编辑。

🎨

配色方案

内置昼间 5 种 + 夜间 5 种共 10 种配色，本地记忆。

⚡

在线更新

检查 GitHub Releases 并自动替换二进制重启。

📱

响应式面板

1.5.1_1 起适配手机 / 平板 / 电脑三种视口，窄屏自动折叠侧边栏。

📋

操作记录

1.5.1_1 起登录、登出与全部修改操作按 IP 留痕，保留 14 天并实时滚动。

整体架构

单进程内嵌四层
┌────────────────────────────────────────────────┐
│ Web 管理端（单页前端，编译时内嵌 index.html）      │
├────────────────────────────────────────────────┤
│ Axum HTTP 层：REST API + WebSocket 事件推送      │
│  鉴权：Cookie 会话（面板）/ Basic Auth / ws_key   │
├────────────────────────────────────────────────┤
│ 业务层：房间、服务器列表、凭据、SMTP、更新、事件中心 │
├────────────────────────────────────────────────┤
│ EasyTier 内核：组网节点、TUN、P2P 打洞、中继       │
└────────────────────────────────────────────────┘

部署目录

所有运行期数据统一存放于可执行文件同目录，单目录即可维护整套服务。

目录结构
/opt/astral-server/
├── astral-server                 # 可执行文件
├── config.toml                   # 配置文件（Web 端口、账号密码等）
├── servers.json                  # 服务器列表数据（自动生成）
├── audit_log.json                # 操作记录（保留最近 14 天，自动生成）
├── avatar.bin                    # 本机头像（可选）
└── Email/                        # 邮件模板（首次运行自动生成）
    ├── room_notification.html
    └── room_notification.txt

源码模块划分

模块职责
main.rs入口：解析 run / init / export-web，装配状态并启动 HTTP 服务
config.rsconfig.toml 加载、解析、写回与示例配置生成
http.rsAxum 路由与鉴权中间件（Cookie 会话优先，Basic Auth 兼容）
api.rsREST API 处理器（登录、房间、服务器、凭据、SMTP、更新等）
ws.rsWebSocket：面板推送 + 第三方服务接入 + 控制指令协议
notify.rs事件中心：一处发布，同时驱动 WebSocket 广播与通知邮件
invite.rsAG1. 离线串 / 短码 / 分享链接的生成与解析
mailer.rsSMTP 发信与可外置编辑的模板
node.rsEasyTier 实例生命周期、事件日志、状态快照、凭据
peer_rpc.rsEasyTier 应用层 peer-RPC 入站处理（向客户端广播昵称/头像）
status.rsEasyTier 运行信息 → 前端节点列表 DTO 的转换
store.rs本地文件持久化（servers.json、avatar.bin）
audit.rs操作记录：登录 / 登出 / 修改操作按 IP 留痕，落盘 audit_log.json（保留 14 天），并实时广播 audit 事件
update.rs在线更新：GitHub Releases 检查、下载替换、重启
web.rs通过 include_str! 内嵌的单文件 Web 管理端

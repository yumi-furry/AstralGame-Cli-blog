配置参考

config.toml 是唯一配置文件，同时承载本服务配置与标准 EasyTier 配置两部分。

配置架构

  • [astral_server] 表：本服务配置，由 astral-server 解析并使用；
  • 其余所有表（instance_name、[network_identity]、[[peer]]、[flags] 等）：标准 EasyTier 配置，解析时原样剥离后交给 EasyTier 内核加载。

面板「保存设置」时只重写 [astral_server] 表，EasyTier 部分保持用户手改内容不变。

[astral_server] 配置字段

字段类型默认值说明
web_bindstring0.0.0.0Web 管理端监听地址（0.0.0.0 全网卡，127.0.0.1 仅本机）
web_portint8080Web 管理端监听端口
usernamestring空鉴权用户名；为空则关闭鉴权（生产环境务必设置）
passwordstring空鉴权密码（Cookie 登录校验与 Basic Auth 兼容）
log_levelstringinfo日志级别：trace/debug/info/warn/error
nicknamestringastral-server房间内展示昵称（写入 EasyTier hostname，对端可见）
iconstring🎮房间内展示的本机图标（emoji）
disable_p2pboolfalse是否禁用 P2P 打洞（开启后仅走中继）
enable_tunbooltrue是否创建 TUN 虚拟网卡（MC 局域网发现等场景依赖虚拟 IP）
static_ipv4string空静态虚拟 IP（CIDR，如 10.126.0.1/24）；为空走 DHCP
auto_join_enabledboolfalse守护进程：服务启动后自动加入预设房间
auto_join_codestring空自动加入邀请：短码 / 完整链接 / AG1. 离线串
auto_create_enabledboolfalse守护进程：服务启动后自动创建预设房间（与自动加入二选一）
auto_create_game_idstring空自动创建预设游戏 ID（如 minecraft）
auto_create_game_namestring空自动创建预设游戏名称（如 我的世界）
ws_keystring空WebSocket 第三方服务密钥；留空则启动时自动生成随机密钥
service_control_enabledboolfalse1.4.2_4 新增：允许第三方服务发送控制指令（restart/close/open/join）

[astral_server.smtp] 配置字段

字段类型默认值说明
enabledboolfalse总开关（关闭则不发信）
hoststring空SMTP 服务器主机，如 smtp.qq.com
portint465SMTP 端口（TLS 一般 465，STARTTLS 一般 587）
usernamestring空登录用户名（一般与发件邮箱一致）
passwordstring空登录密码 / SMTP 授权码
from_namestringAstral Server发件人显示名称
from_emailstring空发件邮箱地址
encryptionstringtls加密方式：tls（隐式 TLS/465）/ starttls（587）/ none（不加密）
recipientsstring[][]收件人邮箱列表（面板可维护并写回）

EasyTier 节点配置段

配置项说明
instance_name实例名，固定为 astral-server
hostname主机名（面板昵称写入此字段，对端可见）
dhcp / ipv4虚拟 IP 分配：dhcp = true 时自动分配；false 则用固定 ipv4
listeners本机监听地址（tcp://0.0.0.0:0、udp://0.0.0.0:0，端口 0 表示随机）
[network_identity]组网身份：同网络节点的 network_name / network_secret 必须一致
[[peer]]公共服务器（中继 / 打洞），客户端与服务器共享
[flags]EasyTier 内核开关（压缩算法、默认协议、KCP/QUIC 入站与中继开关等）

示例配置

运行 astral-server init 生成的内置示例配置：

toml
[astral_server]
web_bind = "0.0.0.0"
web_port = 8080
username = "admin"
password = "change-me-please"
log_level = "info"
nickname = "astral-server"
icon = "🎮"
disable_p2p = false
enable_tun = true
static_ipv4 = ""
auto_join_enabled = false
auto_join_code = ""
auto_create_enabled = false
auto_create_game_id = ""
auto_create_game_name = ""

[astral_server.smtp]
enabled = false
host = "smtp.qq.com"
port = 465
username = "your_mail@qq.com"
password = "授权码"
from_name = "Astral Server"
from_email = "your_mail@qq.com"
encryption = "tls"
recipients = ["a@example.com"]

# ws_key = ""
service_control_enabled = false

# ---- 以下是 EasyTier 节点配置 ----
instance_name = "astral-server"
hostname = "astral-server"
dhcp = true

listeners = [
    "tcp://0.0.0.0:0",
    "udp://0.0.0.0:0",
]

[network_identity]
network_name = "astral-net"
network_secret = "please-change-this-secret"

[flags]
data_compress_algo = 2
default_protocol = "tcp"
dev_name = "astral0"
disable_kcp_input = true
disable_relay_kcp = true
enable_relay_foreign_network_kcp = false
disable_quic_input = true
disable_relay_quic = true
enable_relay_foreign_network_quic = false

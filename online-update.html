在线更新

服务器可从 GitHub Releases 检查最新版本并在线下载应用，替换自身二进制后自动重启服务。

版本约定

Cargo.toml 使用 semver 构建号写法（如 1.4.2-4），运行时 / API 展示统一转换为下划线写法（如 1.4.2_4）；解析时两种写法等价。

检查更新

GET /api/update/check 请求 GitHub Releases API（匿名限流 60 次/小时/IP），返回：

字段说明
current_version当前版本
latest_version / latest_name最新 tag / release 标题
update_available是否有更新（语义版本比较）
release_notes / release_url更新说明 / release 页
download_urllinux x86_64 资产直链（无匹配时为 null）

应用更新

POST /api/update/apply，请求体 download_url。安全白名单只允许从以下域名下载：

  • https://github.com/
  • https://objects.githubusercontent.com/
  • https://release-assets.githubusercontent.com/

替换流程（仅 Linux 生效）

  1. 下载新二进制到 <exe>.new（300 秒超时）；
  2. chmod 755 赋予执行权限；
  3. 旧文件改名 <exe>.bak；
  4. .new 原子 rename 为当前路径；
  5. sleep 1 && systemctl restart astral-server（nohup 脱离父进程执行）。

Windows 等非 Unix 平台暂不支持自动重启。
